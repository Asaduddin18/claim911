# Open-source components

This application uses Next.js, React, Tailwind CSS, Radix UI, shadcn/ui components, Lucide, clsx, class-variance-authority and tailwind-merge. The component source generated by the official shadcn CLI is retained in components/ui. Their upstream license notices remain with installed dependencies and must accompany redistribution as required by each license.

- shadcn/ui: https://github.com/shadcn-ui/ui/blob/main/LICENSE.md
- Radix UI: https://github.com/radix-ui/primitives/blob/main/LICENSE
- Lucide: https://github.com/lucide-icons/lucide/blob/main/LICENSE
- Next.js: https://github.com/vercel/next.js/blob/canary/license.md
- React: https://github.com/facebook/react/blob/main/LICENSE
- Tailwind CSS: https://github.com/tailwindlabs/tailwindcss/blob/main/LICENSE

A complete dependency license inventory remains a release task. Models, voices and cloud services have separate terms; installing an open-source SDK does not make hosted inference free.

- axe-core 4.14.0: MPL-2.0. Unmodified evaluation dependency; license and third-party notices are retained in `licenses/axe-core/`. Upstream source: https://github.com/dequelabs/axe-core .

- @bolna/web-call 3.0.1: official MIT-licensed browser SDK, pinned with package lifecycle scripts disabled. Upstream: https://github.com/bolna-ai/web-call . Browser integration must use backend-issued ephemeral sessions; no API key is included in browser code.
